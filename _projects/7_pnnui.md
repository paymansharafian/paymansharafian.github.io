Developed the Parallel Neural Network User Interface (PNNUI) to enable real-time Genetic Algorithm optimization of ARNA's neural control parameters. Resolved critical ROS Python 2/3 dependency conflicts by containerizing the environment and writing custom Bash scripts for RTOS pipeline execution.

The UI runs in a browser and provides live feedback on optimization convergence, allowing researchers to tune controller parameters without stopping the robot.
